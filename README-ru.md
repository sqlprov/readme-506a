API для SQL-запросов (506a)

**Что это**: SQL-шлюз, который принимает любой SQL-запрос и возвращает результат в JSON. База данных - SQLite-совместимая, летает на дохера мощных серверах. Ты единоразово платишь за пожизненный доступ, а не за железо.
Эндпоинт
`POST https://506a.sqlprov.workers.dev`
Заголовки:
`x-key:private_key` (обязательно, без него нихуя не придёт).
Тело запроса:
Сырой SQL-запрос (строка). Пример: `"SELECT * FROM users WHERE id = 1"`
Ответ:
- При успехе: JSON-массив объектов (результат запроса).
- При ошибке (невалидный SQL, проблемы с соединением и т.д.): `[]` (пустой массив) или просто пустое тело. Хуйня, сам разберёшься.

Что поддерживается
- **SELECT**, **INSERT**, **UPDATE**, **DELETE**, **CREATE TABLE**, **ALTER TABLE**, **DROP TABLE**.
- Транзакции (`BEGIN`, `COMMIT`, `ROLLBACK`).
- Стандартные агрегатные функции (`COUNT`, `SUM`, `AVG` и т.д.).
- JOIN, подзапросы, UNION.
- Триггеры не проверял, могут отсутствовать.
Не работает:
- `VACUUM`, `ATTACH DATABASE`, `REINDEX`.
- Полнотекстовый поиск FTS5 - нет.
- Внешние ключи - могут не соблюдаться, но обычно работают.
Лимиты и квоты
- **Максимальный размер запроса:** 5 МБ.
- **Максимальное время выполнения:** 10 секунд (если запрос тупит - ответа не будет).
- **Количество запросов в день:** 100000.
- **Размер базы данных:** 5 ГБ (хватит для любых твоих поделок).
